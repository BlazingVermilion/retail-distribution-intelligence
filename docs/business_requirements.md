# Monthly distribution review

The intended reader is an analyst reviewing Iowa retailer purchasing activity. The project answers three questions: how reported value and bottle quantities changed, whether the figures can be reconciled, and what the next month might look like.

A review must use a named snapshot, preserve reported amounts and caveats, and distinguish a forecast from a historical observation. Dashboards, generated briefs and cloud totals must refer to the same publication when compared. See [observed results](acceptance/RUN_EVIDENCE.md).

The project does not measure consumer demand, audited profit, user adoption or analyst time saved. The brief is an artifact available for human inspection; no external delivery or approval is implied.
